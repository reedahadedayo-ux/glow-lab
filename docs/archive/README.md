Use the [current README](../../README.md), [architecture](../architecture.md), [workflows](../workflows.md), [testing](../testing.md) and [security review](../security-review.md) for the current snapshot. Archive reports are evidence with limits, not production-readiness certifications. No scenario blueprint or email delivery proof is present here.
